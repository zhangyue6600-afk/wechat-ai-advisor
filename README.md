## 🌟 核心特性与架构跃升 (v1.9.0)

1. **绝对零封号安全（100% 合规纯只读）**：
   - 彻底摒弃高危的 DLL 注入、内存写入与网络协议逆向；
   - 底层严格采用 Windows 标准调试/只读权限（`PROCESS_VM_READ`），与系统任务管理器和杀毒软件工作原理完全一致，微信反作弊模块判定为正常合法读操作。
2. **原生多模态视觉直通（看图解题 · 彻底告别传统 OCR）**：
   - 原生支持 Gemini 3.8 / GPT-4o 等多模态视觉大模型；
   - 当群友在群内甩出终端报错截图、显卡拓扑图（如 `nvidia-smi topo -m`）或编译堆栈时，系统自动提取图片流并转为 Base64 直通大模型，毫秒级直接看懂截图中的具体报错行、显存状况并给出针对性解法。
3. **多人群聊多轮滑动上下文 (Thread-Aware) 与【纠错立威模式】**：
   - 维护各群最近 8~12 条多方连续发言流，不放过任何现场交流语境；
   - 决策 Prompt 升级为 5 大核心模块，新增 **`🛡️【群内局势透视与纠错立威建议】`**：若有其他群友给出外行、容易炸卡或有安全隐患的误导方案，一针见血指出其硬伤，并给出一键纠错的权威标准解法，帮使用者在群聊中瞬间确立资深架构师地位。
4. **领域同义词矩阵与高权算力加权 RAG 检索器**：
   - 内置 GPU 算力、大模型推理部署与二手交易 7 大同义词图谱（如 `OOM/显存溢出/爆显存`、`卡死/hang/堵塞`、`多卡/通信/NCCL/NVLink/NUMA`、`Gaudi2/高迪/Habana`、`量化/FP8/AWQ` 等）；

## 📖 快速上手指引（五步成师）

### 第一步：大模型 API 配置
- **公网/反代 API**：如 Gemini / DeepSeek 官方，填写接口地址与 API Key，模型填 `gemini-3.8-flash-high` 或 `deepseek-chat`。
- **本地/局域网私有模型（如 vLLM / Ollama / LMDeploy）**：
  - **接口地址**：填本地或内网实际地址（例如 `http://127.0.0.1:8000/v1`）；
  - **API Key**：本地模型无鉴权，留空或填 `EMPTY` 均可；
  - **模型名称**：填部署的模型 ID（例如 `qwen2.5-7b` 等）；
  - 点击 **[保存并测试连通性]**，系统将自动发起通信并显示测试耗时。

### 第二步：多群选择与扫描
- 确保电脑已登录 Windows 微信客户端；
- 在会话列表可勾选单个或**多个群聊/私聊**，点击 **[合并提炼所选会话]**。

### 第三步：五维立体血肉知识库构建
- 勾选【五维立体深度血肉知识库（全量并发穿透）】；
- 系统自动启动分层萃取引擎：
  - 阶段 1/2：全量聊天高浓度微观事实提取；
  - 阶段 2/2：大模型推理架构师、社会学分析师、硬件买手三大专家多路并发交叉重构；
- 提炼完成后可一键下载完整 ZIP 知识库包。

### 第四步：知识库一键增量同步与热沉淀
- 后续群聊产生新消息时，点击【一键增量同步】，系统自动根据时间戳只抓取新增记录；同时监听中产生的高价值解答会自动进入热沉淀卷。

### 第五步：开启群军师实时心跳监控
- 开启后，系统以 **0.8 秒高灵敏度** 轮询本地消息更新；
- 军师建议卡片实时弹现（支持多模态截图解答与现场纠错），剪贴板精准自动同步回复草稿，您扫一眼直接按 `Ctrl+V` 发送！
