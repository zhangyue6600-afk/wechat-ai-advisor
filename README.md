# 微信群 AI 军师 · WeChat-AI-Advisor (v1.8.0)

> 面向微信群聊的一体化 AI 军师与深度知识库挖掘系统：全自动群聊只读解密、万条信息高吞吐多阶事实萃取、**五维立体血肉知识库构建（技术避坑/人物图谱/黑话暗号/行情晴雨/Prompt注入）**、群内发言人深度历史画像、毫秒级实时心跳监听与高水平专家回复生成。

---

## 🌟 核心特性与设计哲学

1. **绝对零封号安全（100% 合规纯只读）**：
   - 彻底摒弃高危的 DLL 注入、内存写入与网络协议逆向；
   - 底层严格采用 Windows 标准调试/只读权限（`PROCESS_VM_READ`），与系统任务管理器和杀毒软件工作原理完全一致，微信反作弊模块判定为正常合法读操作。
2. **顶尖级五维立体血肉知识库引擎（5D Knowledge Hub）**：
   - 告别传统简单的关键词搜索与切片抽样，采用 Map-Reduce 式多阶并发蒸馏：
     - **01_核心技术专题与实测避坑手册.md**：分类沉淀经过多方实战验证的技术解法与排障指南；
     - **02_关键人物档案与人设图谱.md**：刻画核心群友的技术专长、硬件配置与社群生态位；
     - **03_圈内特有黑话与隐语缩写词典.md**：破解圈内暗语缩写与行业特有行话；
     - **04_真实硬件行情晴雨表与选型避坑指南.md**：整理二手收售底价、硬件选型搭配与采购防坑建议；
     - **05_全景社群系统Prompt注入规范.md**：将社群认知结晶化为 Agent 骨髓世界观。
3. **发言人全景历史画像分析（Sender Profiling）**：
   - 每次群友发言，自动关联其过去在该群的历史发言与立场风格，让军师看穿发言人真实意图与技术背景。
4. **4 维度高水平专家建议卡片**：
   - 🎯 **推荐回复草稿**：直接给出最高水平答复，自动同步系统剪贴板，一秒 `Ctrl+V`；
   - 👤 **发言人画像与生态定位**：分析发言人角色、技术段位与过往行为特征；
   - 🔍 **意图剖析与潜台词拆解**：解读字面下的真实动机与心理博弈；
   - 🧠 **专家推演与思考过程**：展示军师背后的谋略论证与推演路径。
5. **智能中文分词与时间感知混合 RAG（Hybrid RAG）**：
   - 引入中文 n-gram 语义分词、停用词过滤与时间戳衰减权重，支持搜“猫哥”、“周末聊的配置”等自然口语。
6. **私有/本地大模型深度兼容**：
   - 既支持公有云商业接口（DeepSeek、GPT-4o、Claude、Kimi 等），也原生适配局域网或本地部署模型（如通过 vLLM / Ollama / LMDeploy 部署的 `Qwen-27B` 等）；
   - 局域网请求自动绕过代理，原生兼容各大模型的思考链（Reasoning / Thinking）输出。
7. **多会话并行与主动问答坐诊抽屉**：
   - 顶部会话药丸标签（Pills Tabs）一键无感切换，智能聚焦剪贴板同步；
   - 右侧滑出式【💬 知识库专家主动坐诊抽屉】，无需等待群友发言，随时像请教军师一样直接问答检索。

## 📖 快速上手指引（五步成师）

### 第一步：大模型 API 配置
- **公网 API**：如 DeepSeek 官方，填写 `https://api.deepseek.com/v1`，输入您的 API Key，模型填 `deepseek-chat`。
- **本地/局域网私有模型（如 vLLM / Ollama / LMDeploy）**：
  - **接口地址**：填本地或内网实际地址（例如 `http://127.0.0.1:8000/v1`）；
  - **API Key**：本地模型无鉴权，留空或填 `EMPTY` 均可；
  - **模型名称**：填部署的模型 ID（例如 `qwen2.5-7b`、`gemini-3.8-flash-high` 等）；
  - 点击 **[保存并测试连通性]**，系统将自动发起通信并显示测试耗时。

### 第二步：多群选择与扫描
- 确保电脑已登录 Windows 微信客户端；
- 在会话列表可勾选单个或**多个群聊/私聊**，点击 **[合并提炼所选会话]**。

### 第三步：五维立体血肉知识库构建
- 勾选【五维立体深度血肉知识库（全量并发穿透）】；
- 系统自动启动分层萃取引擎：
  - 阶段 1/2：全量聊天高浓度微观事实提取；
  - 阶段 2/2：大模型推理架构师、社会学分析师、硬件买手三大专家多路并发交叉重构；
- 提炼完成后可一键下载完整 ZIP 知识库包。

### 第四步：知识库一键增量同步
- 后续群聊产生新消息时，点击【一键增量同步】，系统自动根据时间戳只抓取新增记录，打成情报补丁无缝融入现有知识卷中。

### 第五步：开启群军师实时心跳监控
- 开启后，系统以 **0.8 秒高灵敏度** 轮询本地消息更新；
- 军师建议卡片实时弹现，剪贴板精准自动同步回复草稿，您扫一眼直接按 `Ctrl+V` 发送！
