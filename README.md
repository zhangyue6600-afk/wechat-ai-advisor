# 微信群 AI 军师 · WeChat-AI-Advisor (v1.6.2)

> 面向微信群聊的一体化 AI 军师与知识库挖掘工具：全自动群聊只读解密、高保真长上下文去噪清洗、AI 知识库结构化提炼、毫秒级实时心跳监听与高水平专家回复生成。

## 🚀 核心特性与设计哲学

1. **绝对零封号安全（100% 合规纯只读）**：
   - 彻底摒弃高危的 DLL 注入、内存写入与网络协议逆向；
   - 底层严格采用 Windows 标准调试/只读权限（`PROCESS_VM_READ`），与系统任务管理器和杀毒软件工作原理完全一致，微信反作弊模块判定为正常合法读操作。
2. **私有/本地大模型深度兼容**：
   - 既支持公有云商业接口（DeepSeek、GPT-4o、Claude、Kimi 等），也原生适配局域网或本地部署模型（如通过 vLLM / Ollama / LMDeploy 部署的 `Qwen-27B` 等）；
   - 针对局域网（192.168.x.x）请求自动绕过代理，并原生支持思维链模型（Thinking / Reasoning 结构体），彻底杜绝空指针异常。
3. **全消息语义意图分析**：
   - 不再机械式判断是否有问号，对群内每句有实质内容的发言进行意图识别（求助、吐槽、架构探讨、观点争议）；
   - 只要群友抛出有探讨价值的话题，军师立即为您生成专业、高逼格的切入回复建议。
4. **知识库优先 + 联网搜索互补（双轨 RAG）**：
   - 优先检索群内过往数万条真实踩坑与实测经验（群内共识权重最高）；
   - 遇到知识盲区或最新外部动态时，自动调用联网搜索引擎检索一手资料；
   - 严禁机械客服腔，严格学习技术群友自然、精炼、直指本质的对话口吻。
5. **高效人机协同闭环**：
   - 军师秒出方案 -> 自动写入系统剪贴板 -> 您扫一眼直接按 `Ctrl+V` 发送；
   - 回复看板新增 **[🔄 重新生成]** 按钮，不满意一秒换一换；
   - 内置一键卸载脚本与自动热更新检测程序。

## 📖 快速上手指引（五步成师）

### 第一步：大模型 API 配置
- **公网 API**：如 DeepSeek 官方，填写 `https://api.deepseek.com`，输入您的 API Key，模型填 `deepseek-chat`。
- **本地/局域网私有模型（如 vLLM / Ollama / LMDeploy）**：
  - **接口地址**：填本地或内网实际地址（例如 `http://127.0.0.1:8000/v1` 或 `http://<您的局域网IP>:8000/v1`）；
  - **API Key**：本地模型无鉴权，直接填 `EMPTY` 或留空即可；
  - **模型名称**：填部署的模型 ID（例如 `qwen2.5-7b`、`deepseek-r1` 等）；
  - 点击 **[保存并测试连通性]**，系统将自动发起通信并显示测试耗时。

### 第二步：登录微信并搜索目标群
- 确保电脑已登录 Windows 微信客户端；
- 在群聊搜索框输入群名或备注（如 `vllm`、`交流`），点击 **[搜索]**；
- 列表中将列出匹配的群聊名称、群 ID 与成员规模，点击 **[选择此群]**。

### 第三步：扫描历史记录与选择提取范围
- 系统将展示该群在底层的总消息量与最早/最新时间跨度；
- 可选择提取范围：**全部历史记录**、**最近 30 天** 或 **最近 7 天**；
- 点击 **[开始提炼 AI 知识库与导出]**。

### 第四步：AI 知识库提炼与一键打包
- 支持两种提炼模式：
  - **极速归档模式**：秒级解密、去噪并打包 Markdown 与 JSONL 原始聊天记录；
  - **大模型深度技术蒸馏（推荐）**：自动分片并调用大模型提取标准化技术 Q&A 问答对与排错避坑手册。
- 点击 **[下载知识库 (.ZIP)]**，可一键保存并分享给朋友。朋友丢入任意大模型即可获得相同推理能力。

### 第五步：开启群军师实时心跳监控
- 开启后，系统以 **0.8 秒高灵敏度** 轮询本地消息更新；
- 支持 **多会话顶部药丸标签一键切换** 与 **智能聚焦剪贴板同步**，绝不串台或冲掉剪切板；
- 右侧一旦捕获到值得切入或解答的技术话题，立即卡片化弹现建议回复，并自动写入剪贴板；
- 如果对某次回复不满意，直接点击卡片右下角的 **[🔄 重新生成]** 即可！

## 🛠️ 维护与工具脚本说明

- **`启动微信群AI军师.bat`**：一键开启 Web 控制台并在浏览器中打开；
- **`检查并自动更新.bat`**：双击检查最新版本与更新日志，支持秒级热更新补丁；
- **`卸载微信群AI军师.bat`**：一键安全终止所有后台监听进程，清理临时解密缓存并恢复快捷方式。
